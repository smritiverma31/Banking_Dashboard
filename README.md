# 🏦 Banking Dashboard — Power BI

 📊 Short Description

An interactive **Banking Dashboard built in Microsoft Power BI** to analyze loan portfolio, customer segments, risk, default rates, loan status, and geographical performance.

 🛠️ Tech Stack

* Power BI
* Power Query
* DAX
* Data Modeling

✨ Key Features

* KPI cards for **Loan Portfolio, Outstanding Balance, Customers, Active Loans & Default Rate**
* Loan portfolio trend analysis
* Loan status and loan-type analysis
* Customer & income segmentation
* Risk category/bucket analysis
* State-wise outstanding balance
* Default rate by loan type and occupation
* Interactive filters for Branch, Risk Category, Loan Status & Year

💡 Key Insights

* Total Loan Portfolio: 270M
* Outstanding Balance: 89.20M
* Active Loans: 102
* Default Rate: 12.67%
* Home Loans contribute the largest loan portfolio.
* Low-risk customers represent the largest risk segment.
* Maharashtra has the highest outstanding balance.

📈 Business Impact

The dashboard helps banking teams monitor portfolio performance, identify credit-risk areas, analyze loan products, and support data-driven decisions.
